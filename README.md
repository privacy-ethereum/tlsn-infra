# tlsn-infra (Archived)

## This service has been shut down

The PSE-hosted notary server at `notary.pse.dev` (including the WebSocket proxy) was shut down on **March 18, 2026**.

This repository previously contained the infrastructure and CI/CD pipeline for deploying the TLSNotary notary server and WebSocket proxy to Azure SGX-based virtual machines.

As noted in the TLSNotary docs since alpha.13, the notary server was removed from the core TLSNotary project scope. The PSE instance was always intended for development and testing only.
